## 🌐 Обзор
![Flask](https://img.shields.io/badge/Framework-Flask-green) ![SQLite](https://img.shields.io/badge/Database-SQLite-blue)

Этот API предоставляет конечные точки для:
- 🧑💼 Управления клиентами (CRUD-операции)
- 🧮 Расчета платежей с использованием пользовательских формул
- 👨💻 Управления администраторами (Добавление/Удаление/Просмотр)

## 🔗 Базовый URL
```
http://<your-server-ip>:5000/
```

## 📡 Конечные точки API

### 📋 Управление клиентами

#### 1. ➕ Добавить клиента
**`POST`** `/add_client`

Добавляет нового клиента с указанной формулой расчета платежей.

**Тело запроса:**
```json
{
    "name": "client1",
    "formula": "payment * 0.1"
}
```

**Ответы:**
- `201 Created`
  ```json
  {
      "status": "success",
      "message": "Клиент 'client1' добавлен."
  }
  ```
- `400 Bad Request`
  ```json
  {
      "status": "error",
      "message": "Имя и формула обязательны."
  }
  ```
- `409 Conflict`
  ```json
  {
      "status": "error",
      "message": "Клиент 'client1' уже существует."
  }
  ```

#### 2. 🗑️ Удалить клиента
**`DELETE`** `/delete_client/<name>`

Удаляет существующего клиента по имени.

**Ответы:**
- `200 OK`
  ```json
  {
      "status": "success",
      "message": "Клиент 'client1' удален."
  }
  ```
- `404 Not Found`
  ```json
  {
      "status": "error",
      "message": "Клиент 'client1' не найден."
  }
  ```

#### 3. 🔄 Обновить формулу
**`PUT`** `/update_client_formula`

Обновляет формулу для существующего клиента.

**Тело запроса:**
```json
{
    "name": "client1",
    "new_formula": "payment * 0.2"
}
```

**Ответы:**
- `200 OK`
  ```json
  {
      "status": "success",
      "message": "Формула клиента 'client1' обновлена."
  }
  ```
- `400 Bad Request`
  ```json
  {
      "status": "error",
      "message": "Имя и новая формула обязательны."
  }
  ```
- `404 Not Found`

#### 4. 💰 Рассчитать платеж
**`POST`** `/calculate_payment`

Вычисляет платеж для указанного клиента на основе его формулы.

**Тело запроса:**
```json
{
    "client_name": "client1",
    "payment": 1000
}
```

**Ответы:**
- `200 OK`
  ```json
  {
      "status": "success",
      "payment": 100.0,
      "formula": "payment * 0.1"
  }
  ```
- `400 Bad Request`
  ```json
  {
      "status": "error",
      "message": "Имя клиента и сумма обязательны."
  }
  ```
- `404 Not Found`

#### 5. 📜 Список всех клиентов
**`GET`** `/get_all_clients`

Получает список всех клиентов.

**Ответы:**
- `200 OK`
  ```json
  {
      "status": "success",
      "clients": [
          [1, "client1", "payment * 0.1"],
          [2, "client2", "payment * 0.2"]
      ]
  }
  ```

### 👨💻 Управление администраторами

#### 6. ➕ Добавить администратора
**`POST`** `/add_admin`

Добавляет нового администратора.

**Тело запроса:**
```json
{
    "id": "123123123"
}
```

**Ответы:**
- `201 Created`
  ```json
  {
      "status": "success",
      "message": "Администратор '123123123' добавлен."
  }
  ```
- `400 Bad Request`
  ```json
  {
      "status": "error",
      "message": "ID администратора обязателен."
  }
  ```
- `409 Conflict`

#### 7. 🗑️ Удалить администратора
**`DELETE`** `/remove_admin/<id>`

Удаляет существующего администратора.

**Ответы:**
- `200 OK`
  ```json
  {
      "status": "success",
      "message": "Администратор '123123123' удален."
  }
  ```
- `400 Bad Request`
- `404 Not Found`

#### 8. 📜 Список всех админов  
**`GET`** `/get_all_admins`  

Получает список всех администраторов.  

**Ответы:**  
- `200 OK`  
  ```json
  {
    "status": "success",
    "admins": [
        [123456789],
        [987654321]
    ]
  }
  ```
- `500 Internal Server Error`
  ```json
  {
  "status": "error",
  "message": "Internal server error."
  }
  ```  

## ⚠️ Обработка ошибок
Все ошибки следуют этому формату:
```json
{
    "status": "error",
    "message": "Описание ошибки"
}
```
